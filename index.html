MediStock — Intelligent Medical Store & Pharmacy Platform

An enterprise-grade medical store and pharmacy operations platform engineered with Django REST Framework, MySQL / Django ORM, and React.js. Architected around pharmaceutical regulations and high transaction volumes, it implements a deterministic FEFO (First Expiry, First Out) allocation engine with row-level locks to prevent overselling.

Deterministic FEFO Allocation: Auto-allocates oldest non-expired batches using database select_for_update locking for race-condition prevention.
4-Tier Expiry Management: Automatic classification into ≤7 days, ≤30 days, overstock, and quarantine alerts with stock disposal workflows.
Point-of-Sale (POS) & Billing: Real-time checkout, line-item batch allocation, tax calculations, and printable invoice generation.
Automated Verification: 100% test pass rate across 21 Pytest test suites covering positive, boundary, and negative stock shortage tests.
Python Django 5.0 Django REST Framework MySQL React.js Pytest Docker

Employee Management System (EMS) — Java & MySQL

A production-grade employee management and payroll platform designed to demonstrate Object-Oriented Programming (OOP) best practices, Data Access Object (DAO) architecture, and MySQL JDBC relational integration. Features polymorphism across compensation models, ACID transactions, and departmental analytics.

OOP Class Hierarchy: Concrete implementations (FullTimeEmployee and ContractEmployee) extending abstract Employee and implementing SalaryCalculatable.
DAO Architectural Pattern: Clean decoupling with interface repositories (EmployeeRepository) enabling runtime switching between live MySQL JDBC and an in-memory mock repository.
MySQL Relational Engine: PreparedStatements preventing SQL injection, cascading foreign keys, and complex aggregate reports (SUM, AVG, GROUP BY).
ASCII CLI & Interactive Web Demo: Clean tabular presentation with column-aligned boundaries and a live browser terminal simulation.
